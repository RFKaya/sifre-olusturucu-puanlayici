# References / Kaynaklar

Bu dosyada, projede yararlanılan standartlar, akademik makaleler ve harici araçların bağlantıları listelenmiştir.

## Standartlar ve Yönergeler
- **NIST SP 800-63B (Digital Identity Guidelines - Authentication and Lifecycle Management):**
  - Parola politikalarında karmaşıklık kuralları yerine uzunluk ve sızıntı kontrolünün önemini açıklayan resmi standart.
  - Link: [NIST SP 800-63B](https://pages.nist.gov/800-63-3/sp800-63b.html)

- **OWASP Application Security Verification Standard (ASVS) - Password Security:**
  - Güvenli yazılım geliştirme standartlarında parola güvenliği kriterleri.
  - Link: [OWASP ASVS v4.0](https://owasp.org/www-project-application-security-verification-standard/)

## Harici API ve Servisler
- **Have I Been Pwned (HIBP) Range API:**
  - Parolaların k-Anonymity yöntemiyle güvenli sorgulanmasını sağlayan Range API dokümantasyonu.
  - Link: [HIBP API Docs](https://haveibeenpwned.com/API/v3)
  - Makale: [Cloudflare - Password Leak Checking with k-Anonymity](https://blog.cloudflare.com/validating-leaked-passwords-with-k-anonymity/)

## Kütüphaneler ve Geliştirici Araçları
- **zxcvbn (Dropbox's Password Strength Estimator):**
  - Entropi, klavye desenleri ve sözlük kontrolleri yapan çekirdek kütüphane.
  - Link: [zxcvbn GitHub](https://github.com/dropbox/zxcvbn)
- **Rich (Python Library for Rich Terminal Output):**
  - Terminal ekranında premium tablolar, paneller ve renk kodlu çıktılar oluşturmamızı sağlayan görsel kütüphane.
  - Link: [Rich Documentation](https://rich.readthedocs.io/)
